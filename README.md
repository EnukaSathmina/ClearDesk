## 📌 About

**ClearDesk** is a premium-style Windows desktop utility designed to help users clean, review, and optimize their PC from one modern dashboard.

It includes tools for safe junk cleaning, storage monitoring, duplicate scanning, startup app review, privacy cleanup, system health tracking, and Pro feature activation.

ClearDesk is portable, so users can run it directly from the EXE file without an installer.

---

## ✨ Features

- 🧹 **Safe Junk Cleaner**  
  Scan and clean safe temporary/cache files.

- 📊 **System Health Dashboard**  
  View CPU, RAM, disk usage, startup impact, and health score.

- 💾 **Storage Overview**  
  Monitor disk usage and available space.

- 📁 **Duplicate File Scanner**  
  Detect duplicate files using optimized scanning logic.

- 🔎 **Large File Finder**  
  Find large files in safe user-selected locations.

- 🚀 **Startup Apps Review**  
  View startup apps and startup impact.

- 🔐 **Privacy Cleanup**  
  Clean safe Windows privacy traces without touching sensitive browser data.

- ⭐ **ClearDesk Pro**  
  Includes Pro activation, machine ID licensing, and 3-day trial support.

- 🔄 **Portable Auto Update**  
  Update through GitHub Releases using portable EXE replacement.

## 🛡️ Safety

ClearDesk is built with safety in mind.

It does not delete personal files such as:

- Documents
- Downloads
- Desktop files
- Pictures
- Videos
- Music
- Project files
- Browser passwords
- Browser profiles
- System32 files

If a file is locked, protected, or currently being used by Windows, ClearDesk skips it safely instead of forcing deletion.

## ⭐ Pro Features

ClearDesk includes optional Pro tools:

- Deep duplicate cleanup
- Advanced startup control
- Privacy cleanup tools
- Large file finder tools
- Scheduled cleaning
- Health report generation
- Smart cleanup selection

A 3-day trial is available from the Pro activation window.

## ⚙️ Performance

ClearDesk is optimized to stay smooth on different PCs.

- Lightweight dashboard metrics update live
- Heavy scans run in background workers
- Duplicate scanning groups files by size before hashing
- Large file scans use safe result limits
- Storage scans use caching
- Logs and table rows are limited to reduce lag

## 🖥️ Requirements

For users:

Windows 10 / Windows 11
64-bit recommended

No Python installation is required when using the released EXE.
